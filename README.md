Personal portfolio of **Marcus Lafaiete** — Full Stack Developer. Institutional website showcasing projects, skills, and contact information. Built with Next.js 15 (App Router) and styled with Tailwind CSS 4.

## 🚀 Setup / Getting Started

### 🇧🇷 Pré-requisitos

- Node.js 20+
- pnpm (gerenciador de pacotes recomendado)

### 🇺🇸 Prerequisites

- Node.js 20+
- pnpm (recommended package manager)

### 🇧🇷 Instalação

```bash
git clone https://github.com/marcuslaf/portifolio-next.git
cd portifolio-next
pnpm install
pnpm dev
```

### 🇺🇸 Installation

```bash
git clone https://github.com/marcuslaf/portifolio-next.git
cd portifolio-next
pnpm install
pnpm dev
```

Acesse / Open: [http://localhost:3000](http://localhost:3000)

## 📋 Comandos / Scripts

| Comando | 🇧🇷 Descrição | 🇺🇸 Description |
|---------|--------------|-----------------|
| `pnpm dev` | Inicia o servidor de desenvolvimento | Start development server |
| `pnpm build` | Gera o build de produção | Generate production build |
| `pnpm start` | Inicia o servidor de produção | Start production server |
| `pnpm lint` | Verifica código com ESLint | Lint code with ESLint |
